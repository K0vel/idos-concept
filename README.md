# IDOS Concept

Unofficial redesign concept of the IDOS **Connection** screen, by Artur K.
Not affiliated with IDOS or CHAPS spol. s r.o.

**Open:** https://k0vel.github.io/idos-concept/

On iPhone: open the link in Safari → Share → **Add to Home Screen**. It then launches
full-screen with its own icon and works offline.

This folder is build output. Do not edit it by hand: the sources (design tokens, icons,
prototype template, this build) live in the portfolio project and are rebuilt with
`node idos-pwa-build.js <this-folder>`.

Icons: [Phosphor Icons](https://phosphoricons.com) (MIT) plus custom IDOS glyphs.
